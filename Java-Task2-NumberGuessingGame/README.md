# Number Guessing Game

## Description
This is a Java-based Number Guessing Game.
The computer generates a random number between 1 and 100,
and the player has to guess the number.

## Features
- Random number generation
- Too High / Too Low hints
- Maximum 7 attempts
- Score tracking
- Play Again option

## Technologies Used
- Java
- Java Collections
- Random class

## How to Run
1. Open the project in VS Code.
2. Compile the Java program.
3. Run the program.
4. Enter a number between 1 and 100.

## Output
The game displays whether the guessed number is
Too High, Too Low, or Correct.
